# 積立投資シミュレーション

元本・積立額（月額）・年利率・運用期間をスライダーで動かすと、将来の資産推移がリアルタイムに更新される、シンプルな積立投資シミュレーターです。HTML / CSS / JavaScript のみで構築されており、ビルドや依存パッケージは不要です。

## 特徴

- **元本**（0〜1億円）、**積立額**（月額 0〜50万円）、**年利率**（0〜20%）、**運用期間**（1〜40年）をスライダーで調整可能
- 入力に応じて以下をリアルタイムに計算・表示
  - 最終残高
  - 総投資額
  - 運用益
- 資産推移を折れ線グラフ（SVG）で可視化

## 使い方

`index.html` をブラウザで開くだけで利用できます。サーバーの起動やビルド作業は不要です。

```
index.html をダブルクリック、またはブラウザにドラッグ＆ドロップ
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| [index.html](index.html) | ページ構造・入力コントロール・結果表示エリア |
| [styles.css](styles.css) | 全体のスタイル（ダークテーマ、レスポンシブレイアウト） |
| [script.js](script.js) | 積立シミュレーションのロジックとグラフ描画 |

## 計算ロジック

毎月、以下の複利計算を運用期間（月数）分繰り返します。

```
残高 = 残高 × (1 + 年利率 / 100 / 12) + 月額積立額
```

- 総投資額 = 元本 + 積立額 × 積立月数
- 運用益 = 最終残高 − 総投資額

詳細は [script.js](script.js) の `getProjection` 関数を参照してください。

## 技術スタック

- Vanilla JavaScript（フレームワーク・外部ライブラリなし）
- SVG によるグラフ描画
- レスポンシブ対応の CSS Grid レイアウト
